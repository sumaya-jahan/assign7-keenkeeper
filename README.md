# KeenKeeper

KeenKeeper is a friendship management web application that helps users maintain meaningful relationships by tracking contacts, interactions, and relationship goals.

## Live Site

https://bucolic-salamander-b84bd8.netlify.app

## GitHub Repository

https://github.com/sumaya-jahan/assign7-keenkeeper

## Features

* View all friends in a responsive card layout
* Dynamic Friend Details page using React Router
* Search friends by name
* Filter friends by relationship status
* Track interactions (Call, Text, Video)
* Timeline page with Local Storage support
* Statistics dashboard with charts
* Responsive design for mobile, tablet, and desktop
* Custom 404 Not Found page
* Toast notifications for user interactions

## Technologies Used

* React
* React Router DOM
* Tailwind CSS
* DaisyUI
* Recharts
* React Toastify
* Local Storage
* Vite
